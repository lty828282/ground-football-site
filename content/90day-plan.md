# 1. GREEN GROUND 벤치마킹 & 경쟁 지형

**※ 확인 참고:** GREEN GROUND 인스타 계정은 외부 열람이 차단되어(로그인 필요) 직접 스크래핑하지 못함. 아래는 "인스타 기반 훈련일지 판매 브랜드의 전형 + 경쟁 제품군(국꿈사 국가대표 프리미엄 축구일지 등 대형몰 입점 제품, 축구일지 앱)" 근거 분석. 실제 계정 스크린샷 확보 시 정밀화.

## 1-1. 배울 점 (강점 — 우리도 채택)

| 강점 | 왜 통하나 | 우리 적용 |
|---|---|---|
| 통일된 감성 비주얼·브랜딩(초록 테마) | 피드가 브랜드로 각인, 신뢰 | 그라운드유스 톤·컬러 시스템 정립 |
| 동기부여 콘텐츠(명언·선수 스토리) | 저장·공유 유발 → 도달 확대 | **우리가 쌓는 멘탈 문구/이야기가 그대로 무기** |
| 명확한 실물 제품 + 선물 수요 | 입학·졸업·생일 시즌 판매 | 실물 노트 + 선물 패키지·각인 옵션 |
| DM·스토리로 직접 소통, 후기 리그램 | 친밀감·전환율 ↑ | 스토리 질문스티커 → DM 커머스 |
| 릴스(숏폼)로 신규 도달 | 알고리즘 확산 | 릴스 우선 편성 |

## 1-2. 약점 (우리가 파고들 빈틈 — 차별화 포인트)

| 경쟁사 약점 | 우리의 보완(차별화) |
|---|---|
| **① 인스타에 갇힘 → 검색 유입 0.** 콘텐츠가 흘러가 사라짐 | **SEO 웹사이트 보유.** 검색에 쌓여 24시간 유입. 인스타는 유입구, 웹은 저수지 |
| **② 실물 노트 단발 판매 → 리텐션 약함** | **디지털+웹 트래커+데일리 문구**로 매일 재방문. 노트는 시작, 생태계로 묶음 |
| **③ 오디언스를 '소유'하지 못함**(알고리즘·계정정지 리스크) | **이메일/카톡 구독 = 내 자산.** 플랫폼이 바뀌어도 고객이 남음 |
| **④ 콘텐츠가 수작업 → 확장 한계** | **자동화 보유**(카드뉴스·멘탈 문구/이야기 매일 자동 생성) |
| **⑤ '기록'에 집중, '멘탈 코칭'은 약함** | **멘탈 코칭이 핵심 정체성.** 코치 톤 문구·이야기 + 교사 운영자 신뢰 |
| **⑥ 축구 단일 → 확장 어려움** | **멘탈 자산은 종목 중립** → 야구·태권도·수영 에디션 확장 |
| **⑦ 커뮤니티가 일방향(브랜드→고객)** | **지역 커뮤니티·Q&A·UGC**로 양방향. 학부모끼리 묶는다 |

## 1-3. 포지셔닝 한 문장
> "GREEN GROUND가 **기록하는 노트**를 판다면, 그라운드유스는 **기록 + 멘탈 코칭 + 성장 커뮤니티**를 잇는 곳이다. 초등교사가 만들고, 검색되고, 매일 돌아오는."

# 2. 2025~2026 트렌드 (플랜 반영 근거)
- **숏폼(릴스) 우선**: 신규 도달은 릴스에서. 정보성·감성 숏폼 → 프로필 방문 → 구독.
- **DM 커머스**: 스토리 질문·투표 스티커 → DM 대화 → 판매.
- **브랜드=콘텐츠+커뮤니티 통합 생태계**: 커뮤니티를 함께 굴리는 브랜드가 승리.
- **저장·공유 최적화 캐러셀**: '광고'보다 '도움되는 정보'가 저장·확산.
- **학부모 아카데미(영양·심리) 수요 확대** → 멘탈 콘텐츠 적기.
- **마이크로 인플루언서·크리에이터 협업**: 지역 코치·축구맘 계정 협업이 효율적.

# 3. 방문객을 "묶어두는" 리텐션 아이디어 (8범주)
**[기존자산]** = 지금 사이트(카드뉴스 자동화·유튜브 피드·Supabase·멘탈 문구/이야기)로 바로 가능.

- **A. 첫 이탈 막기**: 관련 글 자동 추천 [기존자산] / 연재로 '다음 편' 걸기 [기존자산] / 3분 인터랙티브 진단(포지션 퀴즈).
- **B. 구독 전환(가장 중요 — 경쟁사가 못 하는 '소유')**: 리드마그넷(멘탈노트 7일 샘플·학부모 체크리스트) → 이메일/카톡 등록 [기존자산] / 카톡 채널·주간 뉴스레터·데일리 멘탈 문구 [기존자산].
- **C. 커뮤니티·소속감(약점⑦ 공략)**: 지역 오픈채팅, 학부모 Q&A(코치 답변), 월간 온라인 밋업.
- **D. 도구·유틸(리텐션 최강 — 약점② 공략)**: 성장 트래커 [Supabase] / 디지털 멘탈노트 [기존자산] / 지역 디렉터리(지도).
- **E. 연재·시리즈**: 요일별 고정 편성, 「이주의 멘탈 이야기」 [기존자산].
- **F. 참여·UGC**: 우리 아이 자랑 게시판, 이달의 리틀 히어로, 클럽·장비 후기·별점.
- **G. 게임화·보상**: 출석·연속방문 배지, 성장일지 스트릭, 포인트→노트 할인, 7일 멘탈 필사 챌린지 [기존자산].
- **H. 개인화**: 나이·포지션→맞춤 피드, 관심 지역→동네 소식, 이름 뉴스레터·생일 축하.

# 4. 90일 실행계획 (트렌드·벤치마킹 반영)

원칙: 매출보다 **구독(소유 자산)**과 **재방문**을 먼저. 완성 전에 판다(사전판매). 재고 0(디지털·텀블벅 선주문).

## Phase 1 (Day 1–30) — 브랜딩 통일 + 그릇 만들기
| 주 | 핵심 작업 | 벤치마킹/트렌드 포인트 |
|---|---|---|
| 1주 | GA4·애드센스 데이터 정리 / **브랜드 톤·컬러 통일**(피드 각인) / 관련글 추천 설치 | 경쟁사 강점(비주얼) 채택 + 약점①(SEO) 강화 |
| 2주 | **리드마그넷+구독 장치** 설치(멘탈노트 7일 샘플) / 카톡 채널 개설 | 약점③(소유) 공략 — 구독 자산화 |
| 3주 | **릴스 주 3회** 시작(멘탈 문구 카드→숏폼), 스토리 질문스티커 소통 | 트렌드: 숏폼 도달 + DM 커머스 준비 |
| 4주 | 요일별 고정 편성 + 「이주의 멘탈 이야기」, 지역 오픈채팅 개설 | 약점⑦(커뮤니티) 공략 |

**Day 30 목표:** 구독자 100명, 릴스 1개 이상 '저장 100+'.

## Phase 2 (Day 31–60) — 수요 검증(지갑) + 커뮤니티
| 주 | 핵심 작업 | 벤치마킹/트렌드 포인트 |
|---|---|---|
| 5–6주 | 멘탈노트 7일 샘플 무료 배포 + **7일 필사 챌린지**(완주 인증 UGC) | 약점②(리텐션)·⑤(멘탈) 공략 |
| 7주 | **사전판매 랜딩+텀블벅** 오픈 / **DM 커머스**(스토리→DM 주문) | 트렌드: DM 커머스 / 재고 0 |
| 8주 | 지역 코치·축구맘 **마이크로 크리에이터 협업** 3인, 후기 리그램 | 트렌드: 크리에이터 협업 |

**Day 60 목표:** 사전예약 30건+, 챌린지 완주 인증 20건+.

## Phase 3 (Day 61–90) — 출고 + 생태계·확장
| 주 | 핵심 작업 | 벤치마킹/트렌드 포인트 |
|---|---|---|
| 9–10주 | 정식판 발송(디지털 즉시/실물 제작), 구매 후기 UGC 수집 | 선물 시즌(입학·졸업) 패키지 |
| 11주 | **디지털 멘탈노트(웹)** 베타 + 상시 판매 + 제휴광고(클럽·용품) | 약점②(재구매) 극복 |
| 12주 | 90일 리뷰 / **종목 확장 테스트**(야구·태권도 에디션 표지) | 약점⑥(종목) 공략 |

**Day 90 성공 기준(3개 중 2개):** ① 구독자 300명+ ② 유료 누적 50건+ ③ 재구매/추천 발생.

# 6. KPI
- **도달/리텐션**: 릴스 도달·저장수, 재방문율, 체류시간, 페이지/세션
- **구독(소유 자산)**: 이메일/카톡 구독자, 방문→구독 전환율(2~5%)
- **수익**: 사전예약·유료 전환율·객단가, 애드센스/제휴
- **참여**: 뉴스레터 오픈율(30%+), 챌린지 완주율, UGC 수, DM 문의수

# 7. 리스크 & 주의
- **기능 과욕 금지**: 90일엔 우선순위 ①~④ 집중, ⑤는 착수만.
- **인스타 의존 낮추기**: 반드시 구독(이메일/카톡)으로 소유 자산화 — 경쟁사 최대 약점을 우리는 피한다.
- **아동 개인정보**: 구독·트래커는 최소 수집·부모 동의.
- **종목 중립 유지**: 멘탈 자산은 처음부터 확장 가능하게.
