# 멘탈코칭 노트 – 문구 은행 (mental-quotes)

유소년 운동선수용 멘탈코칭 노트의 **필사(따라쓰기) 문구 모음**입니다.
축구를 넘어 야구·태권도·수영 등 유소년 운동선수 전반에 쓰도록 종목 중립적으로 작성합니다.

## 파일

- `mental-quotes.csv` — 문구 데이터베이스. 컬럼: `번호, 카테고리, 문구, 유형`

## 카테고리

`노력·기준` / `실패·회복탄력성` / `자신감·멘탈` / `꾸준함·인내` /
`팀워크·태도·인성` / `목표·꿈` / `승부·경쟁` / `기본기·과정` / `몸·회복·습관`

## 유형 (저작권 정책 — 중요)

이 노트는 **판매 제품**이므로 모든 문구는 저작권 안전해야 합니다.

- **오리지널** — 그라운드유스가 처음부터 창작한 문장. 저작권 100% 본인 소유.
- **각색(인터뷰 영감)** — 선수 자서전/다큐/인터뷰에서 다룬 *주제·통찰*을 얻되,
  **원문을 인용하지 않고** 유소년 눈높이의 새로운 문장으로 다시 쓴 것. 특정 인물의
  말로 귀속(인용)하지 않으므로 저작권·오귀속(misattribution) 위험이 없음.

> ⚠️ 실존 인물의 명언을 **그 사람 말로 인용**하려면, 인쇄 전 반드시 공식 출처의
> 원문·표기를 확인할 것. 애매하면 '각색' 처리해 자체 문장으로 대체.

## 자동 채굴 루틴

매일 15개씩(자서전 5 · 다큐/유튜브 5 · 스포츠심리 5 버킷) 주제를 조사해
오리지널 문장으로 다듬어 `mental-quotes.csv`에 추가하고 커밋한다.
중복을 피하기 위해 추가 전 기존 문구를 확인한다.
